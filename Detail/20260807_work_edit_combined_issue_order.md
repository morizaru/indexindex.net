# 2026-08-07 作品編集画面 合併号の掲載リスト順修正

## 対象

- `indexindex/admin/work_edit.php`
- `indexindex/work.php`
- 確認対象URL: `https://morizaru.net/indexindex/admin/work_edit.php?id=30950`

## 症状

作品編集画面の掲載リストで、同一年の号数が次のように並んでいた。

```text
週刊少年サンデー 2021年21号
週刊少年サンデー 2021年24号
週刊少年サンデー 2021年22・23合併号
```

本来は次の順に並ぶ必要がある。

```text
週刊少年サンデー 2021年21号
週刊少年サンデー 2021年22・23合併号
週刊少年サンデー 2021年24号
```

## 原因

前回の号数順修正では、`mi.issue_label` の「年」と「号」の間を取り出し、完全な数字の場合だけ号数として扱っていた。

`2021年22・23合併号` の場合、取り出される文字列は `22・23合併` になるため、完全一致の数字判定 `^[0-9]+$` に合わず、号数として使われなかった。

その結果、`24号` より後ろに回ることがあった。

## 修正内容

`issue_label` から抽出した号数部分の判定を、完全な数字ではなく「先頭が数字」の判定に変更した。

```sql
REGEXP '^[0-9]+'
```

MySQL の `CAST(... AS UNSIGNED)` は先頭の数字を数値化できるため、`22・23合併` は `22` として扱われる。

この対応により、合併号は先頭号数ベースで並ぶ。

- `2021年21号` -> 21
- `2021年22・23合併号` -> 22
- `2021年24号` -> 24

管理画面 `admin/work_edit.php` と公開作品ページ `work.php` の両方に同じ修正を反映した。

## 確認

- `admin/work_edit.php` の `issue_label` 号数判定を `^[0-9]+$` から `^[0-9]+` に変更。
- `work.php` の同判定も同様に変更。
- 変更差分は合併号判定の正規表現変更のみ。
