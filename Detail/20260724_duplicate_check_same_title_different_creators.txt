duplicate_check.php 同名作品・作者違いタブ追加 調査修正詳細
作業日: 2026-07-24

対象
- indexindex/admin/duplicate_check.php

要望
- 管理画面の重複チェックツールに、同じ作品名で作者が違う作品を確認できるタブを追加する。

調査結果
- 既存の duplicate_check.php には以下の2タブがあった。
  - 人物名チェック
  - 作品名チェック
- 既存タブは、人物または作品そのものの重複候補を表示し、必要に応じて統合SQLを出力する作りだった。
- 今回の要望は「作品名は同じだが作者が違うもの」を確認する用途であり、単純に作品IDを統合する前提では危険なため、統合SQL出力の対象からは外す方針にした。

修正内容
- allowed_types に same_title_different_creators を追加した。
- タブナビに「同名作品・作者違い」を追加した。
- 同名作品・作者違い用の取得関数 fetch_work_creator_candidates() を追加した。
  - works を基点に issue_contents、content_creators、creators をLEFT JOIN。
  - 作品ごとに creator_ids と creator_names を GROUP_CONCAT で集計。
  - 既存の検索モード contains / normalized / prefix / all と同じ流れで候補を絞り込み。
- 正規化済み作品名ごとにグループ化し、同じ作品名の中で creator_ids の組み合わせが2種類以上あるグループだけ表示するようにした。
- 結果表示では、以下を表示するようにした。
  - ID
  - 作品名
  - サブタイトル
  - かな
  - 区分
  - 作者
  - 掲載件数
  - 編集リンク
  - 公開リンク
- 同名作品・作者違いタブでは、既存の統合SQL出力フォームを表示しないようにした。

検証
- C:\xampp\php\php.exe -l indexindex\admin\duplicate_check.php
  - No syntax errors detected
- git diff --check indexindex/admin/duplicate_check.php
  - 空白エラーなし

注意点
- DB接続を使った実データ表示確認はこの作業環境では行っていない。
- 作者違いは creator_id の組み合わせで判定している。
  - 作者名が同じでも人物IDが分かれている場合は別作者として扱われる。
  - 先に人物名重複チェックで人物IDを整理すると、結果の精度が上がる。
- content_creators に作者が未登録の作品は creator_ids が空になる。
  - 作者未登録と作者登録済みの同名作品も「作者違い」として出る可能性がある。

今後行ったほうがいいこと
- 同名作品・作者違いタブに「作者未登録を含める/除外する」フィルタを追加する。
- creator_id の組み合わせだけでなく、作者名を正規化して比較するモードを追加する。
- 作品名の正規化キー、作者セット、掲載件数をSQL側で集計する専用ビューを作る。
  - データが増えるとPHP側で候補8000件を処理する方式は重くなる可能性がある。
- 結果グループごとに「同一作品の可能性」「別作品の可能性」をメモできる確認ステータスを持たせる。
- 作品統合SQLを出す場合は、作者違いのまま統合してよいか判断が必要なため、通常の作品名チェックとは別の事前確認SQLを用意する。

追加修正
- 「switch」波切敦 と 「Switch」米原秀幸 のように、英字の大小違いだけの作品名が同名作品・作者違いタブに出ない問題があった。
- 原因は、PHP側の正規化では Switch/switch を同じキーとして扱う一方、候補取得の最初のSQL検索がDB照合順序に依存しており、検索語によって片方の大小違い候補がSQL段階で落ちる可能性があったため。
- fetch_work_creator_candidates() の検索条件を LOWER(COALESCE(...)) LIKE に変更し、作品名、サブタイトル、かなの英字大小違いをSQL段階でも拾えるようにした。
- 結果表に「正規化作品名」と「作者ID」を追加した。
  - Switch/switch が同じ正規化キーになっているか確認しやすくするため。
  - 作者名表示だけでは同姓同名や人物ID分裂を判断しづらいため。
- 追加修正後、C:\xampp\php\php.exe -l indexindex\admin\duplicate_check.php で構文エラーなしを確認した。
