# 検索のスペース無視対応と表記ゆれ吸収の改善

## 概要

`indexindex/search.php` で、入力値にスペースが入っているかどうかで検索結果が変わってしまう問題を改善した。 これまで `課長島耕作` と `課長 島耕作` は別物として扱われていたが、どちらでも同じ人物としてヒットするようにした。

また、作品名や作者名に対して表記ゆれを含む入力も、空白を取り除いた比較で拾えるようにした。

## 背景

検索の入力はユーザーが自然に書く形で、例えば次のような差が出やすい。

- `課長島耕作`
- `課長 島耕作`
- `課長　島耕作`

これらは同一人物名として扱われるべきだが、元の実装ではスペースを含む文字列そのものを LIKE で比較していたため、検索条件が一致しにくかった。

## 修正内容

### 1. 空白除去で比較する SQL を追加

`search.php` に以下のような比較を追加した。

- `REPLACE(REPLACE(field, ' ', ''), '　', '')`
- クエリで `LIKE` を使う際も、空白を取り除いた形式で比較する

これにより、以下のような入力差を吸収できる。

- `課長島耕作`
- `課長 島耕作`
- `課長　島耕作`

### 2. 作品/雑誌/作者の検査に空白除去を適用

検索の主要対象に対して、空白を除いた値と入力側の空白除去値を比較するようにした。

これにより、検索文字列の中にスペースが入っていても、表記ゆれとして拾いやすくなった。

### 3. 既存の AND / OR 検索と両立

この修正は既存の `AND` / `OR` 検索ロジックを壊さず、同じ検索時に空白の違いだけで外れてしまうケースを避けるための補正として追加した。

## 期待される挙動

### 例: 作者名検索

入力: `課長島耕作`

- `課長島耕作` でヒット
- `課長 島耕作` でもヒット
- `課長　島耕作` でもヒット

### 例: 作品名検索

入力: `ドラゴンボール`

- `ドラゴン ボール` でも同様に拾える
- 作品名の表記ゆれがある場合も、空白の有無で引っかかりやすくなる

## 補足

ユーザーの指摘のとおり、表記ゆれを管理してデータ側に揃える方法も有効であるが、検索側でもスペース無視・表記ゆれ吸収を入れることで、ユーザー入力の癖に強くなる。 今回は検索側の利便性を高める修正を入れた。
