# 作者名分割ロジック修正レポート

## 問題の概要
URLの `https://morizaru.net/indexindex/admin/content_bulk_add.php` で、作者名を登録する際、スペースで自動分割されていました。

**例：** `小林哲也、DJ SPACE` を入力すると
- **修正前:** 
  - author:小林哲也
  - author:DJ
  - author:SPACE ← スペースで分割されていた

- **修正後（期待値）:**
  - author:小林哲也
  - author:DJ SPACE

## 修正内容

### ファイル
- **ファイルパス:** `c:\moriya\00_main\70_study\30_program\HTML\morizaru.net\indexindex\indexindex\admin\content_bulk_add.php`
- **関数名:** `split_creator_names()`
- **行番号:** 314-337行目

### 修正前のコード
```php
$parts = preg_split('/\s*(?:[,、\/]|\s+)\s*/u', $creator_name);
```

**問題:** 正規表現内に `\s+` が含まれており、スペースが区切り文字として機能していました。

### 修正後のコード
```php
// 修正: スペースを区切り文字から除外 (区切り文字は「、」「,」「／」「/」のみ)
$parts = preg_split('/\s*[,、\/]\s*/u', $creator_name);
```

**修正内容:**
- 正規表現から `\s+` (スペース)を削除
- 区切り文字を `[,、\/]` のみに限定（カンマ、全角コンマ、スラッシュのみ）
- スペースは区切り文字として機能しないように修正

## 区切り文字の仕様
修正後、以下の4つの区切り文字のみで作者名を分割します：
1. **「、」** （全角コンマ）
2. **「,」** （半角コンマ）
3. **「／」** （全角スラッシュ）
4. **「/」** （半角スラッシュ）

**スペースは区切り文字ではない** ため、「DJ SPACE」のような名前も保持されます。

## 修正前後の正規表現解説

### 修正前: `/\s*(?:[,、\/]|\s+)\s*/u`
- `\s*` - ゼロ個以上のスペース
- `(?:[,、\/]|\s+)` - **または** 以下いずれか
  - `[,、\/]` - コンマ系
  - `\s+` - **1個以上のスペース** ← これが問題
- `\s*` - ゼロ個以上のスペース

**結果:** スペースでの分割が発生

### 修正後: `/\s*[,、\/]\s*/u`
- `\s*` - ゼロ個以上のスペース
- `[,、\/]` - コンマ系のみ
- `\s*` - ゼロ個以上のスペース

**結果:** コンマ系のみで分割、スペース分割なし

3. 登録後、以下が反映されていることを確認：

   - ✅ `author:DJ SPACE` （スペース保持）
   - ❌ `author:DJ` と `author:SPACE` への分割なし
