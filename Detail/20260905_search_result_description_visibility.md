# 2026-09-05 検索結果画面の説明文非表示対応

## 対象

- `indexindex/search.php`
- 確認例：`search.php?q=コミックフラッパー`

## 要望

検索実行後の結果画面では、次の案内を表示しないようにする。

- 「INDEXINDEX検索について」
- 「INDEXINDEXに登録されている漫画雑誌の目次情報を、作品名、作者名、雑誌名から検索できます。…」の説明文

## 調査結果

- 対象の説明文は検索キーワードの有無に関係なく常時出力されていた。
- 同じページ内の検索ガイドや検索例は、すでに `$q === ''` の場合だけ表示する実装になっていた。

## 修正内容

- 対象の `.page-description` を `$q === ''` の条件内で出力するようにした。
- キーワード未入力の初期画面では、従来どおり説明文を表示する。
- キーワードが入力された検索結果画面では、検索結果の有無や検索対象に関係なく説明文を表示しない。
- 検索フォーム、検索処理、検索結果の内容には変更を加えていない。

## 確認結果

- `git diff --check`：問題なし。
- 条件分岐とHTML構造を差分で確認した。
- このローカル環境には PHP CLI がないため、`php -l` は未実施。
- テスト環境へのアップロード後、初期画面では表示され、`?q=コミックフラッパー` では非表示になることを要確認。
