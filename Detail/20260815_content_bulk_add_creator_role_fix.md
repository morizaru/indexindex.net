# 2026-08-15 目次一括登録の作者名パース不具合修正

## 対象

- [indexindex/admin/content_bulk_add.php](../admin/content_bulk_add.php)

## 事象

目次一括登録で作者名を次のように入力したとき、

```text
まんが：〇〇　原案：△△
```

期待する保存形式は以下のように分解されるはずだった。

- 〇〇 → 役割: まんが
- △△ → 役割: 原案

しかし、実際には次のように誤解析されていた。

- 〇〇 → 役割: 〇〇 / 役割名なしで author 扱い
- △△ → 役割: 原案

その結果、

```text
作者が役割：〇〇　原案、作者△△
```

のように、人物名と役割が混ざった状態で保存されてしまっていた。

## 原因

[content_bulk_add.php](../admin/content_bulk_add.php) の作者名分割処理は、役割ラベルの検出と名前境界の判定が弱く、連続した役割付き入力で次のようなパターンを正しく切り分けられていなかった。

- 「まんが：〇〇　原案：△△」
- 「まんが:〇〇, 原案:△△」
- 役割ラベルが前方に残っていた場合

特に、`split_creator_roles_bulk()` の正規表現パターンと、`split_creator_names()` の区切り条件が、スペース区切りに偏っており、半角カンマ区切りや複数の役割ラベルの連続入力を安定して処理できていなかった。

## 修正内容

以下を修正した。

- 役割ラベルとして「まんが」「原案」などを認識できるように拡張した。
- 区切り条件に半角カンマ `,` と全角カンマ `，` を含めた。
- 役割付き入力の名前部分に余計な区切り文字が残らないように正規化した。
- 役割ラベルの後続にある名前を、正しく次の人物として認識するようにした。
- フォームの説明文を更新し、複数入力例を半角カンマ区切りで示すようにした。

例:

```text
まんが:〇〇, 原案:△△
```

この形式で入力すると、次のように分解される。

- まんが: 〇〇
- 原案: △△

## 補足

今回の修正により、既存のスペース区切り入力も維持しつつ、より明確な半角カンマ区切りを使えるようにした。

> 例: 「まんが:〇〇, 原案:△△」

## 確認内容

- 役割ラベルの直後に名前が来るケースで、誤って人物名が役割側へ混入しないことを確認。
- 複数役割を連続入力したときに、各人物を正しく分割できることを確認。
- フォーム説明文に半角カンマ区切り例を追加した。
