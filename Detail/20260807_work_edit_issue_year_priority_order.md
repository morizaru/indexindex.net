# 2026-08-07 作品編集画面 雑誌号年優先の掲載リスト順修正

## 対象

- `indexindex/admin/work_edit.php`
- `indexindex/work.php`
- 確認対象URL: `https://morizaru.net/indexindex/admin/work_edit.php?id=30950`

## 症状

作品編集画面の掲載リストで、次のように雑誌号年が混在して表示されていた。

```text
週刊少年サンデー 2018年53号
週刊少年サンデー 2020年1号
週刊少年サンデー 2019年1号
週刊少年サンデー 2020年2・3合併号
週刊少年サンデー 2019年2・3合併号
週刊少年サンデー 2020年4・5合併号
週刊少年サンデー 2019年4・5合併号
週刊少年サンデー 2019年6号
```

本来は、雑誌号としての年と号数を優先し、概ね次のように並ぶ必要がある。

```text
週刊少年サンデー 2018年53号
週刊少年サンデー 2019年1号
週刊少年サンデー 2019年2・3合併号
週刊少年サンデー 2019年4・5合併号
週刊少年サンデー 2019年6号
週刊少年サンデー 2020年1号
週刊少年サンデー 2020年2・3合併号
週刊少年サンデー 2020年4・5合併号
```

## 原因

前回修正時に、並び順の年判定を `publication_year`、`release_date`、`publication_date` 優先に変更していた。

週刊少年サンデーの年末発売号では、`2020年1号` の発売年・発行年が 2019 年側に入ることがある。

そのため、雑誌号ラベル上は `2020年1号` であっても、並び順では 2019 年扱いになり、`2019年1号` と混在した。

## 修正内容

掲載リストの年ソートを、雑誌号としての年を優先する順に変更した。

優先順位は次の通り。

1. `mi.issue_year`
2. `mi.issue_label` の `年` より前から抽出した4桁年
3. `mi.publication_year`
4. `mi.release_date` の年
5. `mi.publication_date` の年

号数ソートは前回までの修正を維持し、`2021年22・23合併号` のような合併号は先頭の `22` を号数として扱う。

管理画面 `admin/work_edit.php` と公開作品ページ `work.php` の両方に同じ修正を反映した。

## 確認

- `admin/work_edit.php` の掲載リスト `ORDER BY` で `mi.issue_year` と `issue_label` 由来の年を優先するよう修正。
- `work.php` の掲載リスト `ORDER BY` も同様に修正。
- 合併号の号数抽出処理は維持。
