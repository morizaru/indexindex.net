# 2026-08-08 トップページ「現在の収録状況」の件数不一致修正

## 対象

- [indexindex/index.php](../index.php)

## 確認内容

管理画面の雑誌本体一覧では登録されている雑誌数が 301 件、目次登録件数 0 の雑誌は存在しない状態だったのに、トップページの「現在の収録状況」で表示される登録雑誌数が 291 件に落ちていた。

## 原因

トップページの統計表示は、[indexindex/index.php](../index.php) 内で SQL を実行して集計していたが、雑誌数・雑誌号数・目次件数のカウントに `mi.status = 'approved'` を含む条件が付いていた。

そのため、公開状態が `approved` 以外のレコードや、目次登録がない雑誌・号が含まれない状態になり、管理画面側の登録件数と一致しない結果になっていた。

## 修正内容

トップページの「現在の収録状況」表示用カウントを、登録済みの全件数を表示するように変更した。

具体的には、以下の集計を行うようにした。

- 登録雑誌数: `SELECT COUNT(*) FROM magazines`
- 登録雑誌号数: `SELECT COUNT(*) FROM magazine_issues`
- 登録作品数: `SELECT COUNT(*) FROM works`
- 登録人物数: `SELECT COUNT(*) FROM creators`
- 登録目次件数: `SELECT COUNT(*) FROM issue_contents`

## 確認結果

- 対象ファイル [indexindex/index.php](../index.php) にエディタ上の構文エラーはない。
- PHP CLI がこの環境に存在しないため、`php -l` の実行は未実施。

## 備考

今回の修正は、トップページの表示件数を「登録済みデータの総数」に合わせるもの。公開状態で絞り込む表示とは分けて扱うようにしている。
