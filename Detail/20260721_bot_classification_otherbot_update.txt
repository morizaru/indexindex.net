2026-07-21 INDEXINDEX Other Bot 個別分類追加

作業日時
--------
2026-07-21

対象ファイル
------------
- indexindex/includes/access_logger.php

目的
----
直近1週間の「Other Bot User-Agent内訳」で Other Bot に分類されていた既知Botを、個別の bot_name として集計できるようにする。
admin/access_analytics.php のBot集計で、SERankingBacklinksBot、OAI-SearchBot、ChatGPT-User、DuckDuckBot などの実体が見やすくなることを目的とした。

変更内容
--------
1. ii_access_is_bot($ua) のBot判定キーワードを追加した。
   汎用の bot / crawl / spider 判定より前に、今回追加する個別Botのキーワードを配置した。

2. ii_access_detect_bot_name($ua) に個別分類を追加した。
   bot 文字列を含むUser-Agentが Other Bot に落ちないよう、汎用判定より前で分類するようにした。

3. 既存分類は維持した。
   Googlebot、Bingbot、GPTBot、Amazonbot、ClaudeBot、PerplexityBot、Applebot、Meta External Agent、Facebook、Facebot、CCBot、DataForSeoBot、PetalBot、Bytespider、SemrushBot、AhrefsBot、MJ12bot、DotBot、YandexBot などの既存判定は残している。

確認SQL
-------
Bot日別集計確認:

SELECT
    access_date,
    bot_name,
    SUM(count) AS cnt
FROM access_bot_daily
WHERE access_date = CURDATE()
GROUP BY access_date, bot_name
ORDER BY cnt DESC;

Other Bot のUser-Agent内訳確認:

SELECT
    bot_name,
    user_agent,
    SUM(count) AS cnt
FROM access_bot_user_agents_daily
WHERE access_date = CURDATE()
  AND bot_name = 'Other Bot'
GROUP BY bot_name, user_agent
ORDER BY cnt DESC
LIMIT 50;

注意点
------
- YaK/1.0 は User-Agent に bot 文字列を含まない可能性があるため、yak/ または linkfluence でBot判定する。
- 今回の変更は User-Agent 文字列による分類追加のみ。
- SQL Injection判定、Blocked IP Hash判定、Behavior Bot / Distributed判定、Behavior Bot / Distributed Work判定、access_bot_daily集計、access_bot_user_agents_daily集計、通常アクセスの access_logs 保存処理は変更していない。
- この環境では php コマンドが PATH に存在しなかったため、php -l による構文チェックは実行できなかった。
