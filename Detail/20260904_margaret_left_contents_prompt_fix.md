# 2026-09-04 マーガレット左側Contents抽出漏れ修正

## 対象

- `indexindex/admin/toc_extract_tool_ai.php`

## 追加確認した内容

- ユーザー提供画像はマーガレット[月2回刊]の見開き目次。
- 右ページ側には大きな「マーガレット」ロゴと作品リストがあり、前回AI抽出ではこの右側だけが抽出対象になっていた。
- 左ページ上部には英字の `Contents` 見出しがあり、漫画作品の目次行が並んでいる。
- 左上Contents欄は、作品名、作者名、右端の黒い吹き出し状ページ番号で構成される。
- 左ページ下部には、カラーグラビア、まんがセミナー、お知らせ、アンケートなど漫画作品以外の項目も混在するため、左ページ全体を無条件登録対象にはできない。

## 修正内容

- マーガレット[月2回刊]向け `additional_instruction` を強化。
- 右ページの大きな目次だけで止めず、左ページ上部の `Contents` パネルを漫画作品目次として必ず確認するよう明記。
- 左ページ上部の形式として、右端に黒い吹き出し状・ギザギザ状の開始ページ番号があることを指示に追加。
- 300番台以降の後半ページ作品も、ページ番号が大きいことを理由に除外しないよう明記。
- 左ページ下部のカラーグラビア、まんがセミナー、お知らせ、アンケート類は漫画作品として登録しないよう明記。
- 共通プロンプトにも、見開き画像では左右ページを別々に確認し、`Contents` / `もくじ` / `目次` の小さなパネル内作品行も登録対象にする指示を追加。

## 方針

- 参考データはAIへの読み取り補助例としてのみ使用。
- 実際の登録データは、AI抽出後に確認画面で管理者が確認・修正してから `content_bulk_add.php` へ渡す。
- 特定号のデータをコードで固定登録する処理は追加していない。
