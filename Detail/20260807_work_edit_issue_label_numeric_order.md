# 2026-08-07 作品編集画面 掲載リスト号数順修正

## 対象

- `indexindex/admin/work_edit.php`
- `indexindex/work.php`
- 確認対象URL: `https://morizaru.net/indexindex/admin/work_edit.php?id=1838`

## 症状

作品編集画面の掲載リストで、同一年の号数が次のように並んでいた。

```text
週刊少年サンデー 1959年1号
週刊少年サンデー 1959年20号
週刊少年サンデー 1959年2号
```

本来は数値順として、次の順に並ぶ必要がある。

```text
週刊少年サンデー 1959年1号
週刊少年サンデー 1959年2号
週刊少年サンデー 1959年20号
```

## 原因

`admin/work_edit.php` の掲載一覧SQLは、主に `mi.issue_no` を数値化して並べていた。

ただし、`mi.issue_no` が空または数値として使えないデータでは、号数ラベル `mi.issue_label` の `1959年20号` / `1959年2号` を数値として解釈できず、最終的に `mi.id` 順へ落ちていた。

その結果、登録ID上で `20号` が `2号` より前にある場合、画面でも `20号` が先に表示されていた。

## 修正内容

`mi.issue_label` から「年」と「号」の間の数字を抽出し、数値として `ORDER BY` に使うようにした。

日本語文字の `年` / `号` は、既存コードと同じく `UNHEX()` で指定し、ファイル文字コードの影響を受けにくい形にした。

並び順は概ね次の優先順位にした。

1. 発行年、発売日、発行日、号年から算出した年
2. `mi.issue_no` の数値
3. `mi.issue_label` の `年` と `号` の間から抽出した数値
4. 発行月
5. 雑誌号ID、掲載順

また、公開作品ページ `work.php` にも同じ `issue_label` 号数抽出を追加し、管理画面と公開画面で掲載履歴の順序がずれないようにした。

## 確認

- `admin/work_edit.php` の掲載一覧SQLに、`issue_label` から号数を抽出する条件を追加。
- `work.php` の掲載一覧SQLにも同様の条件を追加。
- `mi.issue_no` が空でも `1959年2号` を `2`、`1959年20号` を `20` として扱えるようにした。

## 備考

ローカル環境では `php` コマンドが認識されないため、`php -l` による構文チェックは未実行。
