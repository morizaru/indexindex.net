# デバッグログ表示チェックボックス常時表示修正レポート

## 問題点の確認

### 修正前の問題
- **登録前のページ** (`?issue_id=18794`)
  - チェックボックス：**表示されない** ❌
  - ログ：表示なし

- **登録後のページ** (`?issue_id=18794&saved=1&inserted=23`)
  - チェックボックス：**表示される** ✅
  - ログ：チェック状態に応じて表示

**結論:** チェックボックスが登録後だけ表示されるため、意味がない

### 原因
HTML内のチェックボックスが `<?php if ($message !== ''): ?>` 条件内に配置されていた
```php
if ($message !== '') {  // 登録メッセージがある時だけ表示
    // チェックボックス
    // ログ表示エリア
}
```

---

## 修正内容

### 修正方針
1. **チェックボックスを常に表示** - 登録前後に関わらず表示
2. **ログコンテンツは条件付き表示** - 登録後（$debug_info がある）のみ表示
3. **登録前ユーザーへの説明表示** - 機能の説明メッセージを追加

### 修正の詳細

#### 修正1: チェックボックスの位置変更（1805-1810行目）
**修正前:**
```php
if ($message !== '') {
    // ... メッセージ表示
    
    // チェックボックス（条件内）
    <div>
        <input type="checkbox" id="toggleDebugLogs" ...>
    </div>
    
    // ログ表示エリア
}
```

**修正後:**
```php
// ✅ チェックボックス（常に表示）
<div>
    <input type="checkbox" id="toggleDebugLogs" ...>
</div>

if ($message !== '') {
    // メッセージ表示のみ
}

// ✅ ログ表示エリア（debug_infoがある時のみ）
if (!empty($debug_info)) {
    // ログ内容
}
```

#### 修正2: 説明メッセージの追加（1851-1856行目）
登録前のユーザーに向けて、チェックボックスの意味を説明
```html
<!-- 登録前ユーザーへの説明 -->
<?php if ($message === ''): ?>
    <p style="color: #999; font-size: 12px; margin-top: 10px;">
        💡 チェックボックスをONにすると、登録後に作者名の分割処理ログが表示されます
    </p>
<?php endif; ?>
```

## ユーザーフロー

### シーン1: ユーザーが初めてページを訪問
```
1. ページロード: ?issue_id=18794
2. チェックボックスが表示される（チェックなし）
3. 説明メッセージが表示される
4. ユーザーが「次回はログを確認したい」と判断
5. チェックボックスをONにする
```

### シーン2: 登録するまでの流れ
```
1. チェックボックスON状態でフォーム入力
2. 登録ボタンをクリック
3. POST送信
4. 登録処理が実行される
5. セッションにデバッグ情報を保存
6. リダイレクト: ?saved=1&inserted=23&debug_logs=1
```

### シーン3: 登録後
```
1. リダイレクト先ページロード
2. チェックボックスが表示（チェック状態を保持）
3. ログが表示される（チェック状態に基づき）
4. ユーザーがログを確認
5. チェックボックスで表示/非表示を切り替え可能
```

## 改善のメリット

| メリット | 説明 |
|---------|------|
| **常時利用可能** | 登録前からチェックボックスが見える |
| **直感的** | ユーザーが事前にチェック状態を設定できる |
| **説明付き** | 登録前ユーザーに機能が説明される |
| **状態保持** | チェック状態をURLで保持 |
| **無駄がない** | チェックしなければログは表示されない |
