# クイックガイド - デバッグログ表示制御

## 修正概要
✅ **登録完了画面の「詳細ログ」をチェックボックスで制御**
- デフォルト：**ログ非表示**（チェックなし）
- チェック時：ログを表示 + URL更新
- ページリロード時：選択状態を保持

---

## 使用方法

### 1️⃣ 通常の利用（ログ不要）
```
1. 目次データを入力
2. 登録ボタン → 登録完了
3. ✅ 成功メッセージ表示
4. ✅ ログは非表示のまま
```

### 2️⃣ ログを確認したい場合
```
1. 登録完了画面で、下記チェックボックスをON
   □ 詳細ログを表示（作者名分割処理）
   ↓
   ✅ チェック
2. ✅ ログが即座に表示される
3. ログで分割結果を確認
   例：
   □ author:小林哲也
   □ author:DJ SPACE  ← スペースで分割されない ✓
```

### 3️⃣ 再度ログを非表示にする
```
1. チェックボックスを OFF
   ✅ チェック
   ↓
   □ チェック
2. ✅ ログが即座に非表示
```

## 修正内容のポイント

| 項目 | 説明 |
|------|------|
| **デフォルト** | チェックなし（ログ非表示） |
| **表示形式** | チェックボックス1つで制御 |
| **即座反映** | クリック直後に表示/非表示が変わる |
| **リロード保持** | ページリロード時に選択状態を維持 |
| **URL変更** | チェック時に `&debug_logs=1` が付く |
| **パフォーマンス** | 初期ロード時はログ非表示で軽い |

## 動作確認チェックリスト

### 初回ロード時
- [ ] チェックボックスが表示される
- [ ] デフォルトはチェックなし
- [ ] ログは表示されていない

### チェック時
- [ ] ログが即座に表示される
- [ ] URLに `debug_logs=1` が追加される
- [ ] ログの内容が正確（スペース分割なし）

### ページリロード時
- [ ] チェック状態が保持される
- [ ] ログが表示されたままになる

### チェック解除時
- [ ] ログが即座に非表示
- [ ] URLから `debug_logs` が削除される

## トラブルシューティング

### Q1: ログが表示されない
**A:** チェックボックスがチェック状態になっているか確認してください

### Q2: チェックしてもログが表示されない
**A:** 登録時に作者名が入力されていない可能性があります（ログは作者名入力時のみ記録）

### Q3: ページリロード後、ログが消える
**A:** 仕様です。セッションデータは最初の表示時に削除されます

### Q4: URLパラメータが増える？
**A:** はい。チェック状態をURLで保持するため `&debug_logs=1` が追加されます
